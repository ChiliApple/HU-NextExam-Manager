# Screenshots

Beispiel-Screenshots des Tools mit ausgemaskierter Schul-Identität.

## Dateien

- `settings.png` - Settings-Tab mit allen Task-Feldern (Shares, OUs, WMI-Filter,
  GPO-Prefix, Firewall-Einstellungen)
- `msi-pull.png` - MSI Pull-Tab mit Release-Info, Task-Liste (Status + Shares),
  Auto-Pull-Konfiguration

## Erstellt via

- OCR (Tesseract) auf invertiertem Bild
- Schulspezifische Begriffe mit schwarzer Box überdeckt
- Python `PIL.ImageDraw.rectangle`
